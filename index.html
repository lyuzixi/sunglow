算法原理与计算流程（提炼自公开的火烧云定量预报教程）
  • 几何模型（火烧云三角）：用抛物线 z(x)=h+x·tanθ+x²/(2R) 近似光线路径（R 为地球半径）。远边界由地球遮挡决定：|θ|=√(2h/R)；近边界由云边界遮挡决定：|θ|=d/(2R)（d 为沿日出/日落方位的云边界距离）。因此只有当 d < 2√(2Rh) 时，云底才可能被照亮，2√(2Rh) 即「霞光深入距离」。
  • 等效地表高度：气溶胶消光系数随高度指数衰减 σ(z)=σ₀·e^(−z/Hs) 时，光线被消光到无法穿透的高度为 z=Hs·ln(AOD/(Hs·k₀))（k₀ 取 550nm 气溶胶消光系数阈值 0.02 /km）。等效云底高度 = 云底高度 − 等效地表高度。
  • 光追消光：沿上述抛物线路径对瑞利散射（τ∝λ⁻⁴）与气溶胶米散射（τ∝λ⁻¹·³）做数值积分，得到 400–700nm 的透射光谱，再经 CIE 1931 色度函数换算为颜色与色饱和度。550nm 透射率 T 决定亮度等级。
  • 云属判据：卷层云/高层云最壮观，卷云、高积云次之，层积云一般，低层云与雨层云几乎不成霞；云底越高、云边界越远颜色越红、持续时间越长。
  • 日出日落线速度：采用按纬度与日期查表的经验值（约 21 km/min@赤道、18 km/min@30°N、14 km/min@50°N），用于把几何距离换算为持续时间。
数据来源、模型说明与免责声明
  • 气象要素（温度、露点、相对湿度、云量、能见度、气压、风、0℃层高度等）来自 Open-Meteo 数值模式接口，分别取 GFS 与 ECMWF IFS 两套模式；气溶胶光学厚度 AOD、PM2.5 来自 CAMS 空气质量接口。
  • 底图由腾讯地图提供（GCJ-02），符合中国地图使用规范；热力与色块为本应用根据气象数据计算生成，不代表官方结论。
  • 光追算法为本地实现的物理模型：在几何可行基础上做多波长消光积分与色度换算，不依赖任何统计订正。
  • 地图的算法模型选择：热力图可分别按 多模型综合 / GFS / ECMWF-IFS / 光追算法 四者之一着色。四套结果在同一次取数中一次性算好并随该日数据缓存，因此切换模型只是换个维度重新插值着色，不会产生新的网络请求；多模型综合＝GFS / ECMWF / 光追 按 0.30 / 0.34 / 0.36 的加权几何平均，某个模型缺数据时自动剔除该项并重新归一（与单点查询口径一致）。若某模型本次确实没有可用结果，选择框中会标注「本次无数据」并置灰，误选时会自动回退到多模型综合并给出提示；整批取数失败（如接口限流）则在地图区显示错误说明，点「刷新地图」重试。
  • 霞光对云的三维分布极为敏感。教程明确指出：短期预报时效不建议超过 36 小时；超过时效或模式间分歧较大时，结论仅作参考，应以临近时刻的卫星云图与实况外推为准。
  • 本程序为科普与辅助决策工具，不构成任何形式的专业气象预报或出行承诺。
