## F1 · 离线可用（PWA 化）

### 核心取舍：做成 `PWA=1` 的**可选产物**，默认仍是单文件
PWA 与"单文件产物"这个核心约束正面冲突 —— SW 的注册脚本必须是同源 http(s) 的
真实 URL（`blob:` / `data:` 一律被拒），所以**单文件 PWA 物理上做不到**。
按规划里定的方案执行：默认构建只产 `index.html` + `404.html`；
`PWA=1` 才多出 `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png`。

### 实现要点
- `assemble.py`：新增 `OUT_DIR`（让探针把另一套构建产到别处，不覆盖仓库产物）、
  `PWA` 开关、`PWA_HOLE = <!--__PWA_HEAD__-->` 占位符（同"不允许残留"纪律）。
  图标复用现成的 `icon_png(n)`（纯 stdlib 手工编码 PNG），192/512 各一张。
- **SW 注册没有新增内联 `<script>` 块**（块数 4 是 syntax.py / globals.js /
  assemble.py 共同守着的不变量）：`_p5.js` 的 `initPWA()` 从
  `link[rel="manifest"]` 的 href 推出 `sw.js` 地址与 scope ——
  manifest 存在即 PWA 版，子路径部署自动成立，不需要再注入地址常量。
- **缓存版本 = 产物内容的 sha256 前 12 位**（`build_id`），不是手写版本号常量：
  内容一变缓存名就变，旧缓存在 activate 时清掉。
- SW 只认一份**预缓存名单**（`./` `index.html` `404.html` `manifest.json` 两张图标），
  stale-while-revalidate；**绝不缓存气象响应**，跨域（气象 / 地图 SDK 与瓦片 / 省界）
  与同源的地图代理 `/_TMapService` 一律不拦截。
- 应用侧 `netOn()` / `refreshNetBar()` / `offlineHint()`：
  离线提示条 `#netBar` 放在 `.top` **外面**（顶栏"窄屏必须一行"是约束 44）；
  取数失败时给**离线专属**文案，而不是"稍候 1 分钟重试"（约束 11 的延伸）。

### 踩的坑（探针侧，两条都很隐蔽）
1. **判"页面就绪"不能写 `window.State`** —— `State` 是顶层 `const`（**词法**全局），

   `window.__navMark`，之后等 `readyState === 'complete' && __navMark !== 标记`），
   且超时**抛错**而不是静默继续。

### 第四次踩「统一行尾」（这次不是脚本，是编辑器）
F4 期间对 `_pi18n.js` 的编辑把它的 **302 个 CRLF 行**统一成了 LF（文件原本
302 CRLF / 800 LF），对 `硬约束详解.md` 把 134 个 CRLF 行改写、又给新行用了 LF。
表现：`commit` 前 `git diff --numstat` 里 `_pi18n.js` 是 **342 增 / 302 删**，
而 `git diff --ignore-cr-at-eol --numstat` 只有 **40 增 / 0 删** —— 差的 302 行
全是行尾噪音。`index.html` 的 649/304 里也有同源的 302 行（它内联 `_pi18n.js`）。
**修法**（`_scratch/eolfix.py`，可复用）：拿 `git show HEAD:<file>` 的原始字节当行尾基准，
用 `difflib.SequenceMatcher` 对**剥掉行尾的正文**比对 —— 正文相同的行还原**原始**行尾，
正文新增/改动的行用原始文件的**主导行尾**；末尾无换行的保持无换行（1102 行保持不变）。
修完 `_pi18n.js` 后重建，**产物从 703,539 → 703,841 字节（+302，恰好是被还原的 CRLF 数）**
—— 也就是说之前那个 703,539 本身就是被污染的行尾算出来的，**文档里的字节数也跟着错了一轮**。
**教训（第四次，且这次是"工具无关"的）**：这个项目里凡是**混用行尾**的文件
（`_pi18n.js` / `硬约束详解.md`），任何"读全文再写回"的路径都会引入噪音；
提交**前**必须用 `git diff --ignore-cr-at-eol --numstat` 与原始 numstat 对一遍，
两者不等就是行尾被动过。
