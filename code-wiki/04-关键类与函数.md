# 04 · 关键类与函数

> 本页是**符号参考**。行号对应当前源码（`79dc85b`）；改代码后行号会漂移，请以符号名为准检索。
> 项目无 class（原生 JS），"关键类"体现为两个全局状态单例：`State`（应用状态）与 `MapMod`（地图模块状态）。

## 1. 全局状态

### 1.1 `State`（[_p5.js:16](../_p5.js)）

| 字段 | 含义 |
| --- | --- |
| `lat / lon / name / region` | 当前查询位置（name/region 来自城市表或 `safeLabel` 清洗） |
| `period / dateStr` | 单点时段（朝霞 am / 晚霞 pm）与日期 |
| `busy / pending` | 预报并发互斥与补跑标志（runForecast 串行化） |
| `result` | 当前预报结果（P/Q/grade/factors/notes/skyCloud…） |
| `cache` | 会话内存单点缓存（键 `pointKeyOf`） |
| `trend` | 趋势结果（按位置缓存 rows） |
| `spots / spotRows / spotMsg` | F2 收藏机位与对比结果 |
| `mapPeriod / mapDim / mapModel` | 地图时段 / 着色维度（p/q/mix/dv）/ 算法模型 |
| `snapRaw / snap / factorRows` | F5 快照原文、解码结果、因素行（供快照挑选） |
| `calib / calibOff` | F4 标注缓存与开关 |
| `folds` | 折叠态（rayFold/notesFold/heroFold/trendFold/legendFold） |
| `units / hour12` | 展示偏好（F7：单位制/12 小时制，只影响显示） |
| `booting` | 启动标志（区分"铺初值"与"用户改地点"） |
