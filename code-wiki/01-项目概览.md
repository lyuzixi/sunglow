# 01 · 项目概览

## 1. 项目定位

**霞光预报（英文名 Glowcast）** 根据气象数据预测**朝霞 / 晚霞（火烧云）出现的概率与观赏质量**。
核心形态是一个**单文件 Web 应用**：`index.html` 内联了全部业务 JS、城市表与 0.5° 高程网格，
可直接丢到任意静态托管；地图模块因腾讯地图 key 不可明文入库，另有**一个可选的服务端中转端点**。

设计上的三个主约束：

1. **单文件自包含** —— 产物即交付物，无打包器、无 npm 依赖、无运行时 CDN；
2. **额度纪律** —— 免费气象接口按访客出口 IP 限流，任何取数都必须由用户显式意图触发或走缓存；
3. **产物不可手改** —— 一切修改发生在 `tpl/` + `_p*.js` + `refs/`，由 `assemble.py` 单向生成产物。

## 2. 功能矩阵

| 模块 | 内容 |
| --- | --- |
| 单点预报 | 输入地点 + 日期 → 概率（%）、质量评分、优/良/一般/差等级；主要影响因素逐项分解（12+1 行） |
| 多模型 | GFS / ECMWF / 光追算法三路各自出分，再用统一权重合成（`W_ENS = 0.30 / 0.34 / 0.36`） |
| 趋势 | 未来 `TREND_DAYS`（10）天逐日打分曲线，可切朝/晚霞；结果落盘缓存，重开页命中时零请求 |
| 地图 | 查询点周边 500 km 局部网格热力图（57 采样点）；白→黄→橙→红分档色阶 + 1 px 等值线 + 凸包外虚线数据范围边界 + 1° 经纬网；四图层开关（数值直标/采样点/云纹/经纬网）；日期、时段、模型切换；悬停/点击出数值；**有缓存开页自动画，零额度** |
| 分享卡 | 一键导出结论卡 PNG（纯 canvas 绘制） |
| 结果快照（F5） | 结论编码进 URL（`snap=`），打开链接**零气象请求**复现结论卡 |
| 最佳窗口（F3） | 未来 N 天按"哪天值得去"排日历格，标 Top3，渲染零取数 |
| 多观测点对比（F2） | 收藏最多 5 个机位一次横向排序，缓存命中的点不进请求 |
| 本地校准（F4） | 用户回填"实际看到了什么"，本机累积统计出校准偏差；**纯展示不回改模型** |
| 使用教程 | `tutorial.html`（四档合一），手写独立文件、不进构建链，与主页共用语言/主题偏好 |
| 多语言 | 简体 / 繁體（台港用语）/ English；键=简体中文原文，缺译回落原文 |
| 深色模式 | 浅色 / 深色 / 跟随系统三态；刷新不闪、`color-scheme` 与原生控件同步 |
| PWA（可选） | `PWA=1` 构建出 manifest/sw/图标，可安装 + 离线打开；默认关闭以保持单文件 |
| 404 页 | 第二个产物 `404.html`，任意深度未知路径下自包含渲染，两个出口 |

## 3. 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 前端 | 原生 HTML/CSS/JS（ES2017+） | 无框架、无构建器、无转译；4 个内联 `<script>` 块共享全局作用域 |
| 地图 | 腾讯地图 GL JS SDK（外链） | 通过同源代理注入 key；色面/等值线/经纬网等全部自绘 canvas/SVG |
| 气象数据 | Open-Meteo（forecast + air-quality） | GFS seamless、ECMWF-IFS025、CAMS 气溶胶 |
| 省界 | 阿里云 DataV GeoJSON | `areas_v3/bound/100000_full.json`，用于掩膜与省份下钻 |
| 构建 | Python 3（仅 stdlib） | `assemble.py` / `mkpreview.py`；图标 PNG 用 zlib+struct 手工编码 |
| 服务端（可选） | Cloudflare Pages Functions | `functions/_TMapService/[[path]].js` 地图 key 代理 |
| 测试 | Node ≥ 22 + Python 3 + Chrome（CDP） | `_check/` 26 项回归，合成数据零额度 |
