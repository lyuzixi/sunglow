# 07 · 测试体系

## 1. 总览

回归套件位于 `_check/`，通过 `python _check/all.py` 一键执行 **26 项**序列。
断言形态以**具名断言**为主（每条断言有名字，失败打印具体条目），总数 **554 条**。
所有浏览器探针跑的是 `_check/preview.html`（腾讯地图 SDK 桩页）——**不是 index.html**。

```bash
python assemble.py && python mkpreview.py   # 前置：重建产物与预览页
python _check/all.py                        # 26 项总表
python _check/all.py -v                     # 附完整输出
python _check/all.py --fast                 # cdp 传 CDP_SEG=fast（跳最慢两段，打印"已跳过"）
python _check/all.py -k <关键词>             # 按名字子串过滤
```

## 2. all.py 的组织

| 成员 | 位置 | 作用 |
| --- | --- | --- |
| `SUITE` | all.py:55–91 | 26 项 `(名字, 文件, 说明[, 环境变量])` 元组列表，顺序即依赖顺序 |
| `OBSERVE` | all.py:93–97 | 观察名单（tzprobe / consistency / shotdefault）：只打印不执行 |
| `remember_facts` | all.py:105–133 | 把探针 `FACTS {...}` 行 + 探针源码 sha1 合并进 `_check/.facts.json` |
| `judge` | all.py:136–182 | 统一判成败：退出码 / `FAIL 计数: N` / `失败 N 项` / FATAL 四类信号 |
| `main` | all.py:190–269 | 逐项 subprocess（UTF-8、单探针超时 900s）→ 打总表 → 失败返回 1 |

**参数语义**：

- `--fast`：只给 `cdp` 注入 `CDP_SEG=fast`，cdp.js 跳过最慢两段（`B5 并发点击`、`算法模型切换`），
  各打一行"已跳过"。语义是"快但仍然端到端"（实测 215 s → 57 s / 51 s）。
- 为什么不做并行：每个探针各占固定调试端口，并行必 `EADDRINUSE`（已踩过）。

## 3. 一键序列（26 项，按序）

`syntax → globals → run_self → datacheck → localgrid → timeoutprobe → zoomprobe → raceprobe →
cachesize → cdp → mapaudit → mobileprobe(390×844) → mobileprobe360(360×640) → persistprobe →
uiprobe → a11yprobe → xssprobe → i18nprobe → darkprobe → spotprobe → snapprobe → calibprobe →
pwaprobe → 404probe → tutorialprobe → docfacts`

顺序约定：静态语法 → 纯函数 → 起浏览器的重活；`mobileprobe` 必须在 `docfacts` 之前
（docfacts 读它的 FACTS 行）。

## 6. 测试工程约束

1. **零额度纪律**：浏览器探针用 `Fetch.requestPaused` 回填合成数据；真实额度只出现在
   `consistency` / `shotdefault` / `shotnext` / `aodscale` / `tzprobe`（故不进一键序列）。
2. **桩必须忠实**：mkpreview 的 Heat 桩按官方核函数叠加语义实现、投影与 `_paint` 共用同一投影；
   桩实现错误会掩盖真实缺陷（曾因桩错掩盖"热力图整片同色"）。
3. **失败信号不统一**是 all.py 存在的主因：`judge()` 收口四类信号；cdp.js 曾"无论如何 exit 0"
   被误报全绿，现由 console.log 包装层登记 FAIL 行 + 退出码双通路。
4. **判据的病 5 类**（`.workbuddy/memory/硬约束详解.md`）：不剥注释 / 按总数断死 / 固定 sleep /
   `window.State` 词法全局 / 计数器最后统一取值。
5. **越界判定参照必须是 `documentElement.clientWidth`**，绝不能用 `innerWidth`
   （溢出会把布局视口等比放大，自指掩盖）。
6. **改源码忘重建 preview ⇒ 整套断言测旧代码** —— 本仓库踩过多次，README 与探针注释都记着。
7. headless 里 SDK 不渲染缩放/罗盘控件，真机专属问题（控件压卡片）只能防御 + 防御性断言。
