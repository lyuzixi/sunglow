「霞光预报」是一个**基于气象数据预测朝霞 / 晚霞（火烧云）出现概率与观赏质量的单文件 Web 应用**。
产物是 `index.html` —— 一个自包含 HTML（内联全部 JS 与城市/高程数据），可直接部署为静态站点；
地图模块另有一个**可选的**服务端中转端点（Cloudflare Pages Functions）。

## 30 秒速览

```bash
python assemble.py          # 拼装 → index.html / 404.html（产物，禁止手改）
python mkpreview.py         # 拼装 → _check/preview.html（带腾讯地图 SDK 桩，探针全跑它）
python _check/all.py        # 一键回归（26 项）
```

- **源码**：`tpl/`（版式）+ `_pi18n.js`/`_p2.js`…`_p6.js`（业务片段）+ `refs/`（内联数据）
- **产物**：`index.html`（804,380 字节，自包含）与 `404.html`；二者**均不得手改**
- **铁律**：改动任何 `_p*.js` / `tpl/` / `refs/` 之后，必须重跑 `assemble.py && mkpreview.py`，
  否则探针测的是旧代码（本仓库踩过多次的坑）

## 术语表

| 术语 | 含义 |
| --- | --- |
| 产物 | `assemble.py` 生成的 `index.html` / `404.html`，禁止手改 |
| 片段（part） | `_pi18n.js`、`_p2.js` … `_p6.js` 等被拼进产物的业务脚本文件 |
| 内联脚本块 | 模板 `tpl/template.html` 里的 4 个内联 `<script>`（构建与探针共同守护的不变量） |
| 探针（probe） | `_check/` 下的回归测试脚本，大多通过 CDP 驱动 headless Chrome |
| 额度 / 计费调用 | Open-Meteo 免费层按 IP 限流的加权请求数，本项目用 `API_CALLS` 记账 |
| 样带（transect） | 沿日出/日落方位由近及远的 17 个采样点（0…400 km），单点与地图共用 |
| 色面 / 值场 | 地图上白→黄→橙→红的插值热力面，由采样点 IDW 生成并自绘到 canvas |
| 凸包 / 外推 | 采样点凸包内=插值可信区，凸包外=外推区（叠可信度纱 + 虚线边界） |
| 双重差分 | 本仓库的验证手法：改前/改后两版产物各跑一遍，逐像素/逐字段比对 |
