## 9. 已知边界（非 bug）

- **纯静态部署地图不可用**：key 不能明文进单文件产物；未配代理时显示说明，属预期。
- **`file://` 双击打开**：地图不起来并显示原因，单点/趋势/分享卡正常，属预期。
- **ELEV_GRID 缺失**：前端退化为"整行单段"，不报错。
- **不翻译的内容**：城市名/省份名（专有名词）、因素表长篇解读与页脚算法说明（"全量"批次已补），
  非中文界面附一行说明。
- **单点 vs 地图口径**：样带 17 点 vs 地图 2 点粗样带，数值可能有差异（`consistency.js` 观察项量的就是它）。
- **源码小瑕疵**：`_p2.js` 顶部 `"use strict"` 拼接后不在脚本首句，实际不生效；`_p6.js avgv` 为无调用方的死代码。
- **`阶段性总结.md` 的历史数字**（如 uiprobe 29 条）是当时点值，现行值以 `README.md` 为准（docfacts 只锁 README 那份）。

## 10. 方法论备忘

- **双重差分**：改前/改后两版各跑一遍，逐像素/逐字段比对（`zoomprobe` 的验收手法）；
- **零行为变化重构**：等价性断言逐位比对 0 容差；
- **测试不骗自己**：断言要有反例能力（`"0 请求"空绿` 配自检断言）；
- **三源互证**：逐行读源码 + 探针反事实测量 + 实拍留证（地图改进勘察方法）。
