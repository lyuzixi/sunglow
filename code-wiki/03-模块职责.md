## 2. 业务片段（`_p*.js`）逐个说明

### 2.1 `_pi18n.js` — i18n 层

- 三语：简体（基准）/ 繁體（台港用语）/ English。**键 = 简体中文原文**（msgid 风格）：
  加文案不需三处同步键名、缺译回落中文原文、词典即待翻清单。
- 词典：`I18N_ZH_HANT`（528 条目）、`I18N_EN`（528 条目，键集合与繁典逐键相等）。
- 翻译函数刻意**不叫 `t()`**：多处存在局部 `const t`，全局 `function t()` 会被静默遮蔽（约束 28）。
- 语言优先级：URL `?lang=` > 偏好存储 > 浏览器语言 > 简体。
- `data-i18n-html`（innerHTML 型翻译）值只可能来自编译期词典常量，不是注入通道。

### 2.2 `_p2.js` — 工具/安全层

- 天文：NOAA 低精度太阳位置、真太阳中天、日出日落（含极昼极夜）、日落线速度查表；
- 安全双闸门：`esc()`（输出侧转义）+ `safeLabel()`（输入侧地名白名单）—— XSS 收口的唯一入口；
- base64url 编解码（快照链接在查询串裸奔）、梯形隶属函数 `trap`、加权几何平均 `wgeo`（一票否决）；
- 城市库解析与三级检索（前缀/音节/包含 + 子串兜底）、球面距离与推点。
- **零副作用**：不碰 DOM / localStorage / 网络。

### 2.3 `_p3.js` — 物理模型层

- 气溶胶垂直分布 → 光学等效地表高度；抛物线光路消光积分（含地球曲率项）；
- CIE 1931 色度 + 5778K 黑体光谱 → 逐波长光追成色（含"污烧"冲淡模型）；
- 云层经验参数化（模式不给云底，由 LCL 与 0℃ 层推）、云属承载评分表；
- 样带云边界分析 `analyseTransect`、火烧云三角几何 `fireGeometry`、亮度 7 档分级。
- **纯函数层**，无任何外部依赖，可被 Node 直接自测。

### 2.4 `_p4.js` — 数据获取 + 评分层

- `jget`：12s 超时 + 指数退避 + **429 双分类**（短时限流退避 / 日额度耗尽 fatal 短路）；
- 取数：`apiForecast`（GFS / ECMWF-IFS）、`apiAQ`（CAMS 气溶胶）+ 240 点分批；
- 计费记账 `API_CALLS` / `apiCallStats`（专供探针断言"首屏 65 调用"）；
- 评分：`scoreStat`（统计判据 9 要素加权 + `trap` 折线）、`scoreRay`（光追 5 采样时刻）；
- **单一来源常量群**：`W_ENS`、`QUALITY_BANDS`（等级阈值+色）、`ENS_CONF_BANDS`、`HEAT_RAMP`（唯一色阶）、
  `API_TZ`（唯一时区口径）、`TRANSECT`（样带几何）。

### 2.5 `_p5.js` — 编排层

- `State` 全局状态单例 + 偏好/折叠/主题/顶栏菜单/目录抽屉等 UI 基础设施；
- `computeAll`：一次预报的完整计算编排（天文→样带→取数→评分→合成→notes）；
- 功能件：F4 本地校准（分桶统计）、F5 快照编解码、F3 最佳窗口、F2 多观测点对比、
  趋势取数与逐日复算、离线 PWA 提示、URL 状态同步。

### 2.6 `_p5b.js` — 渲染层

- `renderAll` 总入口：结论卡（天色带 `skyBand` + 衬线大字概率 + 结论句）、四张模型卡、
  12+1 行因素表、光追细节卡、数据质量注记、本地校准块；
- 快照卡 `renderSnap` 与分享卡 `shareCard`（780×400@2x 纯 canvas）——**全部零取数**；
- 口径纪律：等级/配色/结论/可信度一律复用 `_p4.js` 单一来源，快照与完整卡必然说出同一结论。

### 2.7 `_p6.js` — 地图层（最大片段，4,066 行）

- 局部采样网格（500 km / 120 km / 57 点）与网格点命名；
- 值场：几何层 `buildGeom`（凸包、权重因式分解、高程段筛选、海陆掩膜）+
  取值层 `evalField`（IDW 插值、7 档分档、smoothstep 羽化、边缘噪声）；
- 图层：色面条带、云纹、marching squares 等值线、凸包范围虚线、1° 经纬网、方位/距离环、数值直标、图钉；
- 交互：悬停提示卡（窄屏贴底 dock）、排行榜、省份下钻、全屏；
- 三套缓存键族读写 + `mapCacheSweep` 淘汰 + 日期 LRU；
- 全局收口：`relang`（语言切换重跑所有 JS 生成文案）、`rerenderForTheme`（主题切换重画）。

## 3. 构建与运行支撑

| 文件 | 职责 |
| --- | --- |
| `assemble.py` | 唯一构建入口：读模板与片段 → 数据内联 → 占位符替换 → 填 4 个脚本块 → 校验无残留 → 写产物；`PWA=1` 时再产 manifest/sw/图标；含 PNG 编码器（纯 stdlib） |
| `mkpreview.py` | 读**已构建的** `index.html`，把腾讯地图 SDK 外链整段换成忠实桩（Heat 核函数叠加、投影/unproject、`?noproj/?noheat` 降级开关），产出 `_check/preview.html` 供探针离线断言 |
| `sw.js` | 生成产物：预缓存静态壳 + stale-while-revalidate；跨域与代理一律放行，**绝不缓存气象响应** |
| `functions/_TMapService/[[path]].js` | 可选服务端：4 条上游路由（pingd / checkKey / oversea / service）转发并注入 `TMAP_KEY`；key 永不进产物 |
| `tutorial.html` | 手写独立教程页（四档合一），零外部引用、图标内联 data-URI；与主页共用 `sunsetbot.pref.v1` 的 `lang`/`theme` 字段 |

## 4. 测试与数据

- `_check/`：26 项一键回归（详见 [07-测试体系](07-测试体系.md)）+ 观察项（`consistency`/`shotdefault`/`tzprobe`）
  + 独立项（`pointcache`/`perfprobe`/`aodscale`）+ 截图工具（`_shotonly`/`shotnext`/`styleprobe`）。
- `refs/`：构建期内联数据（城市表/别名/高程）+ 教程正文三份（断言数值溯源，不进产物）。
  `datacheck.py` 断言产物内联数据与 `refs/*.txt` 逐字节一致（防串位）。
