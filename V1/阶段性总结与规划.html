① 项目现状总结

1.1 定位与技术栈

一个单文件、零依赖、纯前端的朝霞/晚霞（火烧云）预报应用：输入地点与日期，输出出现概率、质量评分与等级， 并给出逐项影响因素分解、未来 10 日趋势、周边 500 km 热力图。 核心卖点是"物理模型 + 多模型融合"，而不是调用现成指数——云层几何、大气消光光谱、光追着色全部在浏览器里算。

层面选型说明 / 代价
运行时原生 ES2018+，无框架、无打包器刻意选择：产物必须是一个可双击打开的 HTML。代价是模块化靠文件拼接顺序，不是靠 import
代码组织_p2…_p6.js 六个片段 → 3 个内联 <script>三段共享全局作用域，function 声明会静默覆盖（_check/globals.js 专门守这个）
数据源Open-Meteo（forecast + air-quality）、阿里 DataV 省界、腾讯地图 GL JS无 API key、无 CORS 问题；但气象源单一、免费层仅限非商业
渲染DOM + 手写 Canvas（色面 / 等值线 / 可信度纱 / 图钉）刻意不用 SDK 的 Heat：需要可控的分档色阶与屏幕空间矢量等值线
构建assemble.py（拼装 + 注入）· mkpreview.py（带 SDK 桩的联调页）纯 stdlib，连 PNG 图标都是手写 zlib 编码——好处是"换个 Python 也能跑"
托管静态托管 + 可选 Cloudflare Pages Functions（地图代理）纯静态不消耗任何服务端配额；404.html 由平台接管未知路径

1.4 亮点（值得保住的东西）

工程纪律远超同类个人项目

  1. 428 条具名断言，24 项一键序列，且失败信号统一收口（all.py 的 judge()）——因为各探针"有的 exit 0 只打计数"，漏解析会把失败当成功。
  2. docfacts 让文档不许变谎话：42 条可机读事实（源码行数、产物字节、常量值、探针条数）与 README/总结逐条比对，找不到声明就报 STALE 而不是静默通过。
  3. 语义变更用"第三方参考实现"做双重差分（zoomprobe 的 refThird）：不拿改造前的实现当尺子。
  4. 硬约束有据可查：../.workbuddy/memory/硬约束详解.md 52 条，每条写清"为什么这么定 + 实测数字"，不是拍脑袋。

架构选择干净，边界守得住

  1. 纯计算层与 DOM 层分离：_p2/_p3/_p5b 里 try 为 0，靠 nz()/isNum() 兜底；异常集中在 _p4/_p5/_p6。
  2. 模板/产物彻底分离：产物可随时删掉重建，模板是唯一版式来源。
  3. key 永不进产物：地图代理同源转发，未配置时返回 500 并写明原因，而不是透传上游 4xx 让人猜。
  4. 额度是显式设计目标：API_CALLS 登记表让"首屏几次调用"成为可断言的量，而不是估算。
  5. 单文件约束被认真对待：连 apple-touch-icon 的 PNG 都用 stdlib 手写编码，只为"换台机器也能构建"。

F1 · 离线可用（PWA 化）

推荐优先中期已落地

把整份产物（472 KB）与已缓存的结果做成离线可用：山顶、海边、地铁这类"最需要看霞光预报"的场景恰恰最可能没信号。

用户价值
无网络时仍能打开页面、查看上次算过的结果与缓存的地图/趋势；二次打开近乎秒开。
实现思路
assemble.py 增产物 manifest.json（图标用 data-URI 不可行，需生成第二个文件）+ sw.js；SW 采用 stale-while-revalidate，只缓存同源静态资源与 404.html，绝不缓存 API 响应（避免缓存过期气象数据）。离线时页面需能识别"无网"并明确提示"展示的是 X 时的缓存"。
依赖条件
HTTPS + 同源（静态托管均满足）。与"单文件产物"约束冲突：需接受"产物从 1 个变 3 个"——建议把 manifest/sw 作为可选产物，由环境变量 PWA=1 开关。
涉及模块
assemble.py tpl/ _p5.js（网络状态提示） 新增 404probe 扩展
成本 / 风险
3–5 天。主要风险是缓存失效导致用户看到旧版本——必须在 SW 里带构建版本号，且 assemble.py 注入。
实测（2026-10-17）
按"可选产物"落地：PWA=1 才多出 manifest.json / sw.js / icon-192.png / icon-512.png，默认构建仍是 1 个文件。缓存版本取产物内容的 sha256 前 12 位（不靠人改版本号常量）；SW 只认一份预缓存名单，跨域与同源的地图代理一律不拦截 ⇒ 探针实测"气象请求发了 9 次、缓存里气象条目 0 条"。离线侧真浏览器验过：切 offline 后 reload 页面仍能打开、显示离线提示条、取数失败给的是离线专属文案（不是"稍候 1 分钟重试"）。SW 注册没有新增内联 <script> 块（块数 4 是不变量）：地址由 link[rel=manifest] 推出。新增 _check/pwaprobe.js（18 条断言），序列 22 → 23 项。
