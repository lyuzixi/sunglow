v2 是V1的重写而不是改写：同一套评分算法与数据源，换了一套工程形态（Vue 3 组件化 + 单文件产物） 与信息架构（天色带、多模型对比并入结论层）。下面按「交付形态 → 功能面 → 算法 → 地图 → 顶栏 → 数据」逐段对账， 并列出 v2 目前仍缺的 3 处。

V1：根目录 index.html（assemble.py 拼接） v2：v2/index.html（Vite 单文件） 核对方式：源码 grep + 线上实拍

04算法口径

这部分是“同源”，不是“相似”。已逐项核对：

口径V1v2一致
模型集成权重 W_ENSgfs .30 / ec .34 / rt .36直接 import 同一常量✓
综合指数 mixedIndex0.55·P + 0.45·Q0.55·P + 0.45·Q✓
综合方式非空子集按权重几何平均同式（forecast.ts 注明与 once() 一致）✓
地图取色刻度固定 0–100 绝对刻度、7 档同（HEAT_RAMP 白→黄→橙→红）✓
一致性公式 consist100 − ΔI × 1.9100 − ΔI × 1.9 已修✓ 已对拍
可信度分档阈值18 / 35 / ∞18 / 35 / ∞✓
对拍已做（npm run probe:consist）：脚本从两边源码里原样抽出 consist 表达式与分档阈值， 在同一 ΔI 网格（0…100，16 个点）上比数值。结果：16/16 一致，阈值一致。
／对拍过程中发现并修正了一处真实漂移：v2 曾写成 100 − ΔI（漏了斜率 1.9）， ΔI=20 时会给 80 分「很一致」，而V1是 62 分——分歧被系统性低估。

06顶栏与信息架构

两边都是“两行报头”，但第二行和窄屏策略不同。

V1

行 1：汉堡（目录抽屉入口）/ logo / 标题 / 语言 / 主题；行 2：徽标纯文字右对齐。窄屏保持两行，抽屉可开。

v2

行 1：logo / 导航（结论·趋势·观测场）/ ⚙ 设置 / 简繁 EN / 主题 / 教程图标；行 2：城市 · 日期 · 朝/晚霞 徽标。窄屏隐藏导航且无抽屉。

差别

v2 把教程从导航移成右侧图标（省一格），但代价是窄屏少了一个“去哪”的入口 —— V1的汉堡抽屉正好补这块。

08建议

  • 补移动端目录抽屉（最值得做）：现在 ≤760px 导航直接 display:none，用户没法在长页里跳转，只能滚。V1那套汉堡 + 贴顶栏抽屉可直接搬。
  • 上海陆掩膜：需要一份简化的中国海岸线多边形（或按经纬度栅格预生成），否则海上也会出现色带，观感上“不真实”。
  • 教程深度：v2 教程 54 KB vs V1 156 KB，算法解释与调参说明偏薄，可按V1目录补齐章节。
