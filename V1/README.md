# 霞光预报

> 本文是 [霞光预报 sunglow](../README.md) 的其中一版：V1 原版。

基于气象数据预测**朝霞 / 晚霞（火烧云）出现概率与观赏质量**的单文件 Web 应用。

产物是 `index.html` —— 一个自包含的 HTML（内联全部 JS 与城市/高程数据），
可以直接部署为静态站点；地图模块另有**一个可选的**服务端中转端点。

## 2. 部署

### 2.1 纯静态（地图不可用）

把 `index.html` 丢到任意静态托管即可（Cloudflare Pages、GitHub Pages、对象存储…）。
**查询、趋势、分享卡全部可用**；地图模块因为拿不到腾讯地图 key 会显示一段说明。

> 免费层配额按**访客自己的出口 IP** 计（10000 次/天/人）。静态站不做任何代转，
> 所以站点本身不消耗任何配额，也不需要通过服务器。

### 2.2 带地图（Cloudflare Pages + Pages Functions）

腾讯地图 JS API 的 key **不能明文写进产物**（单文件 HTML，谁都能看到 key 并拿它刷配额）。
腾讯位置服务官方要求公网发布必须改用代理方案，本仓库已实现：

1. 去 [lbs.qq.com](https://lbs.qq.com) 申请一个 **Web 端 (JS API)** key，并把站点域名加进白名单。
2. 把本目录作为 Pages 项目（构建命令留空，产物目录 `/`）。
   `functions/_TMapService/[[path]].js` 会被自动识别为一个 Function。
3. 在 Pages 的 **Settings → Environment variables** 里加：
   ```
   TMAP_KEY = 你的腾讯地图 key
   ```
4. 构建时把地图代理地址指到同源路径：
   ```
   TMAP_SERVICE_HOST=https://你的域名/_TMapService python assemble.py
   ```
   不设这个变量时，`assemble.py` 会回落到本地预览用的占位符形态，开发行为完全不变。

代理与前端同源 ⇒ 没有 CORS、没有混合内容问题。key 只存在于服务端环境变量，
**永不进入产物**。

### 2.2.1 404 页

纯静态站**没有前端路由**，所以「访问不存在的路径」这件事由托管平台兜底：
路径匹配不到任何文件时，平台会取站点根下的 `404.html` 并以 404 状态返回
（Cloudflare Pages / GitHub Pages / Netlify 都是这条约定）。`assemble.py`
会一并生成这个产物，**不需要任何 rewrite 配置**。

页内地址写成**站点根的绝对形式**，由构建期注入：

```
SITE_BASE=/          默认，站点在域名根下（Cloudflare Pages、自定义域名）
SITE_BASE=/仓库名/   GitHub Pages 的项目页这类部署在子路径下的站点
```

本仓库的 Pages 开在 `https://lyuzixi.github.io/sunglow/`（**子路径**），
所以推 GitHub 前要按子路径构建：

```
SITE_BASE=sunglow python assemble.py     # → 404.html 里写 /sunglow/
```

### 可选：PWA（可安装 + 离线条）

```
PWA=1 SITE_BASE=sunglow python assemble.py
```

会多产出 `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png`，页面可被"添加到主屏幕"，
且**离线时仍能打开**（启动壳从 SW 缓存应答）。

> **默认不开**，因为它与"单文件产物"这个核心约束冲突：SW 的注册脚本必须是同源
> http(s) 的真实 URL（`blob:` / `data:` 一律被拒），所以单文件 PWA 物理上做不到。
> 取舍是：**默认仍然是 1 个文件**；想要可安装的人自己开 `PWA=1`，多出的文件由同一次
> 构建产出，不会漂移。
>
> 三条纪律：① SW **绝不缓存气象响应**（过期预报比没有预报更危险），只认一份预缓存
> 名单（同源静态资源 + 404 页），跨域与同源的地图代理一律不拦截；② 缓存名带**产物
> 内容的 sha256 前 12 位**，内容一变旧缓存自动作废，不靠人改版本号常量；
> ③ 注册是"增强"——没有 SW / 注册失败 / `file://` 打开，全部静默跳过。
> 另外 SW 注册**没有**新增内联 `<script>` 块（块数 4 是不变量）：脚本地址由
> `link[rel=manifest]` 的 href 推出，manifest 存在即 PWA 版。

> 换到域名根下部署时直接 `python assemble.py` 即可（默认 `/`）。
> 判据在 `404probe`：站点根不再写死 `/`，而是**从构建好的 404.html 的
> `data-home` 上读出来**，两种部署形态测的是同一条性质。

> 为什么不能写相对地址 `index.html`：`404.html` 是在**请求的那个 URL** 下被返回的，
> 相对地址会按 `/a/b` 解析成 `/a/index.html` —— 越深的错链错得越离谱。
> 写死 `/` 又照顾不到子路径部署，所以跟地图代理走同一条「构建期注入」的路。

页面自带两个出口：**返回首页**（真链接，没有 JS 也能用）与**返回上一页**
（只有在确认有上一页时才显形，否则新标签页会把人扔去一个空白页）。

> **合规**：在中国境内展示地图，底图服务需具备测绘资质。腾讯地图是合规的；
> 为了省一个 key 换成 OSM 之类的境外底图属于把合规问题一起换进来，不建议。

### 2.3 本地预览

`index.html` 里的地图代理地址默认是占位符形态（由运行时替换）。
直接**双击本地文件**打开时，地图不会起来，页面会显示原因说明 —— 这是预期行为，
不是 bug；单点查询不受影响。

要本地联调完整功能：

```bash
python assemble.py          # 生成 index.html
python mkpreview.py         # 生成 _check/preview.html（用 SDK 桩替换腾讯地图脚本）
```

`_check/preview.html` 里的地图 SDK 是**桩实现**：按官方语义复刻了 Heat
（核函数叠加 → 阈值归一）与投影/unproject，可离线、可断言、不消耗任何额度。
回归套件全部跑这个文件。

## 3. 源码结构

单文件产物由脚本拼装，**不要手改产物**：

```
tpl/template.html     版式来源（HTML + CSS + 3 个内联 <script> 占位块）
tpl/404.html          404 页模板（第二个产物，与主产物共用设计令牌）
_p2.js … _p6.js       业务代码片段
refs/*.txt            内联数据（城市表 / 地名别名 / 0.5° 高程网格 b64）
functions/            Cloudflare Pages Functions（地图代理，可选）
assemble.py           拼装 → index.html 与 404.html
mkpreview.py          拼装 → _check/preview.html（带 SDK 桩）
_check/               回归套件
tutorial.html         使用教程页（第三个页面，**手写独立文件、不进构建链**）
```

```bash
python assemble.py && python mkpreview.py
```

改动任何 `_p*.js` / `tpl/` / `refs/` 之后都必须重跑这一对。两个产物**都不许手改**。

> 开发向文档：`../.workbuddy/memory/硬约束详解.md`（必须遵守的规则，含推导与实测数字）。

| `404probe.js` | 404 页：深路径（`/a/b/c?x=1`）下渲染 / 请求路径转义 / 首页链接指向站点根 / 零外部请求 / 桌面与 390×844 窄屏两档视口 / 两个出口可用（**21 条具名断言**） |
| `tutorialprobe.js` | 使用教程页（**独立手写文件**，主页那套探针盖不到）：自包含与引导脚本先于 CSS / **三语词典覆盖全部 272 个 DOM 键** / 繁體「真换字形」与英文「无回落中文」/ 主题三态（auto 跟随系统含**不刷新**的实时跟随、light 压过系统、dark 生效、写回偏好）/ 四档切换与 `#hash` 深链（按 **computed display** 判，不按 `hidden` 属性）/ 与主页**双向互通**（书本图标进、← 回）与偏好键「只补字段、不擦别人的」/ 390·360 无横向溢出且按钮命中测试可点（**34 条具名断言**） |
| `docfacts.py` | 文档↔代码一致性（源码行数 / 产物字节 / 源码常量 / 探针断言条数） |

`--fast` 的语义（C2 改过）：原先它是"把 cdp 整段删掉"，代价是**端到端覆盖一并没了**
（而那正是 cdp 存在的理由）。现在改成给 cdp 传 `CDP_SEG=fast`：它照常起浏览器、照常
跑完前中段的全部断言，只跳过最慢的两段（算法模型切换 —— 与 S5 的 48 组合遍历重叠；
B5 并发点击 —— 另有 `raceprobe` 覆盖），且**各自打一行「已跳过」**，不静默略过。
实测 cdp 段 215 s → **57 s**（普通）/ **51 s**（`--fast`）。

> 为什么不做并行：每个探针各起一个 Chrome、各占一个固定调试端口，并行必然 EADDRINUSE
> （已踩过）。省时间的唯一正路是"少做真正慢的那几段"。

**不进一键序列**（会花真实额度或依赖实时接口）：`consistency.js`、`shotdefault.js`、
`tzprobe.js`。另有 `pointcache.js`（单点缓存专项）与 `perfprobe.js`（绘制性能基线，
只测量、不判成败）。

> `styleprobe.js` / `_shotonly.js` / `shotnext.js` / `aodscale.js` 四个**一次性脚本**已在
> 2026-10-20 的仓库清理中移到仓库外（任务已完成，证据留在归档目录）。前两个的用途分别是
> 「把色面雾感量化成数字」与「换入旧源码后截图」，`shotnext` 是可信度徽标的一次性视觉核对，
> `aodscale` 的结论是「不支持隔点取样，保持 57 点全取」—— 这正是 `pointcache` / `perfprobe`
> 被保留、而这四个被归档的区别：前者还会再跑，后者不会。

> `mobileprobe.js` 现在**在一键序列里**（两个视口各跑一次），**不花额度**（走合成数据）。
> 单独跑：`node _check/mobileprobe.js`；换视口用 `VW=360 VH=640 node _check/mobileprobe.js`
> —— 它必须开触摸模拟，否则量到的是桌面形态。
> **headless 里 SDK 不渲染缩放/罗盘控件**，真机专属的"控件压卡片"问题只能防
> （dock 卡片 `z-index:2000`），探针里对应的是防御性断言而非实测。

> ——这是本项目踩过多次的坑。

## 5. 已知边界

- **额度**：首屏只取单点结果（约 65 个加权调用）；地图数据**必须由用户显式点击才取**
  （约 171 个）。勾选框 `#autoMap` 默认不勾选，因为这个选择会直接影响访客自己的日额度。
  **唯一的例外是"缓存命中"**：上次看过的城市 + 日期在新开页时会**自动画出来**
  （`autoLoadMapFromCache()`），它走的是缓存快路径、**一个请求都不发**，
  所以不占任何额度；没有缓存时仍然只显示「加载周边地图」引导。
  这条边界由 `loadMapData(force, cacheOnly)` 里**一行** `return false` 保证
  （位置在两条缓存快路径之后、网络调用之前），localgrid 用请求计数端到端断住。
- **可信范围**：色面边界＝采样点**凸包** + `FIELD_OUT_KM`（70 km）羽化；**凸包之外即外推**，
  那一圈叠一层可信度纱（与羽化边界、地图上那条虚线是同一条线，实测覆盖已上色面积的约 **21.6%**）。
  悬停卡另给一个**距离**口径（`FIELD_FULL` = 90 km，指"离最近采样点多远"）——
  这与"在不在采样区里"是两个量，别混用：包内实测最远 85 km，贴着凸包顶点外侧只有 1.4 km 却已是外推。
  取值半径 `FIELD_REACH_KM`（120 km）是 `MAP_IDW_MAX` / `TIP_RANGE_KM` 的唯一来源
  （三者写成同一个表达式，避免出现"图上透明、悬停却有值"的环带）。
- **模型分歧**：地图的「模型分歧」维度只取三套模型的极差；少于两套有值时返回
  「无数据」而不是 0 —— 后者会把"少了一套模型"伪装成"三模型高度一致"。
- **高程网格**：`refs/ELEV_GRID_RAW.txt` 缺失时前端自动退化为"整行单段"，不报错。
- **手机端**：窄屏（≤760px）下顶部信息条收成一行、地图提示卡走贴底通栏 ——
  这两条由 CSS 媒体查询与 `tipDock()`（`matchMedia`，与 CSS 同宽）**各管一半**，
  改断点要同时改 `tpl/template.html` 的两处 `@media` 与 `_p6.js` 的 `TIP_DOCK_MQ`。
  桌面形态不受影响（`mapaudit` 的提示卡断言仍按"跟随指针"那套量）。
  卡片共四条关闭路径：× 按钮 / 再点同一处 / 点地图以外 / **拖动地图**（位移 >12 px
  即收，阈值以下是点击，不会误伤"再点同一处"）。**关闭时必须摘掉 `.dock`**：
  窄屏下 `.tip.dock` 带 `pointer-events:auto` + `z-index:2000`，只移除 `.on`
  会留下一块 326×302 的**隐形热区**扣在地图上（地图拖不动、双指还会触发
  浏览器整页缩放）—— `hideMapTip()` 是唯一收口处，必须一起清。
- **移动端布局的一条通用纪律**：任何 `overflow-x:auto` 的滚动容器都要显式
  `min-width:0`（`.t-scroll` 已加）。否则它作为 flex/grid 子项会被内容一起撑开，
  把页面 `scrollWidth` 顶出去，移动端据此放大布局视口 → **整页被缩小**。
  判断用"元素是否越界"，**不要**用"元素是否最宽"—— 横向滚动表格天生就最宽。
- **顶部标题列（`.top-tx`）必须 `min-width:0`**：h1 是 `white-space:nowrap`，
  其 min-content = 整行标题宽，缺 `min-width:0` 时标题列不许收缩，会把 badge
  顶出容器右缘 → `body.scrollWidth` 增大 → 真机可横向拖出空白 + 布局视口被放大。
  只写 `min-width:0`，**别写 `flex:1`**（会跟 `.spacer` 分剩余空间，badge 不再贴右）。
  窄屏标题被 ellipsis 截断是**预期行为**（badge 的地名/日期/时段更值得保留）。
- **`#map` 必须 `touch-action:none`**：否则页面横向溢出时浏览器的横滑手势跟地图
  拖动竞争（真机"地图无法左右滑"）。**绝不能设在 `.mapwrap`** —— `.tip.dock`
  是它的后代且要纵向滚动，手势判定取触摸链上 touch-action 的交集。
- **探针判"越界"的参照必须是 `documentElement.clientWidth`**，绝不能用
  `innerWidth`：溢出会把布局视口等比放大（390 → 451 实测），用 innerWidth 当
  参照的断言**永远抓不到自己制造的溢出**（自指掩盖）。
- **404 页**：`404.html` 是**第二个产物**，由 `assemble.py` 从 `tpl/404.html` 生成，
  同样**不许手改**。它在**任意深度**的未知路径下被返回，所以页内地址必须是站点根的
  绝对形式（构建期注入 `SITE_BASE`，默认 `/`），且**不能有任何外部引用** ——
  这两条由 `404probe.js` 的静态断言守着（占位符残留 / 外部引用各一条）。
  它与主页共用同一份 `:root` 设计令牌，探针会直接比对两个模板的令牌块。
- **使用教程页**：`tutorial.html` 是第三个页面，**手写独立文件、不进 `assemble.py`** ——
  它要能双击打开、断网可读，所以零外部引用、图标内联成 data-URI。设计上与主页同一套
  「纸面仪器」令牌，唯一越界处是开篇那块**整块深色**（那是一块"天"，浅色主题下也保持深色）。
  语言与主题**与主程序共用 `sunsetbot.pref.v1`**：读时整份读、写时只补 `lang` / `theme`
  两个字段（刻意不复用主页 `prefWrite` 的白名单过滤 —— 那会顺手删掉别人写进去的字段）。
  入口两处：顶栏书本图标（`#tutBtn`，真链接）与目录抽屉底部「指南 · 使用教程」。
  这页不在构建链里，所以主页那 20 多个探针**一条都盖不到它**，由 `tutorialprobe.js` 的
  34 条断言单独守着。
- **XSS 防护（S0）**：全项目 49 处 `innerHTML` 插值，此前**没有转义函数**，靠"数据来自内置城市表"
  这一前提兜底 —— 而它至少在两处不成立：省份名来自**外部 GeoJSON**（DataV 省界）；
  `?name=` 会把地址栏里的字符串一路带进结果卡的 `innerHTML`（**一条分享链接即可触发的反射型 XSS**，
  40 字符截断挡不住：`<img src=1 onerror=eval(location.hash)>` 正好 39 字符，超长载荷放 hash 里即可）。
  现分两层收口：输出侧 `esc()`（`_p2.js`，用于文本与引号包住的属性值），
  输入侧 `safeLabel()`（`_p2.js`，URL 地名白名单）。**新增 render 代码时必须走这两个函数**，
  由 `xssprobe.js` 的 18 条断言守着（含"5 个热点是否仍带 `esc(`"这种源码级断言）。
  仍未做的事：CSP（单文件页可用 `<meta http-equiv>`）与其余 44 处的分批替换。
- **多语言（i18n）**：三档语言（简体 / 繁体-中国台湾·香港用语 / 英文），键＝**简体中文原文**
  （msgid 风格），词条只写"与基准语言不同"的那一份 —— 缺译时**回落成中文原文**，
  不会显示 `hero.title` 这种占位符。`setLang()` 只换语言与静态 DOM，动态区域由
  `relang()`（`_p6.js` 末尾）重跑一遍，否则会出现"一半英文一半中文"。
  优先级：**URL `?lang=` > 偏好存储 > 浏览器语言 > 简体**，`syncUrl()` 把语言也写进地址栏，
  所以分享链接会带走语言。**刻意不做翻译的**：城市名/省份名（数据，专有名词）、
  因素表的长篇解读与页脚算法说明（属"全量"批次）——后者在非中文界面下会附一行说明。
  404 页是独立产物，**自带一份最小词典**，HTML 原文恒为简体 ⇒ 没有 JS 时照常可读。
  **覆盖到"全量"**：界面骨架 + 数据质量提示（20 条）+ 因素表的 13 条长篇解读 +
  地图图例两段技术说明 + 页面错误与降级文案 + 页脚的算法原理与数据来源说明。
  含行内标签的长段落走 `data-i18n-html`（写 innerHTML）—— 它的值**只可能来自
  `_pi18n.js` 里那两份编译期常量词典**，永远不接运行时数据，所以不是一条注入通道；
  语言相关的标点（列表分隔符）也收口到 `listJoin()`，免得英文界面里出现
  `temperature、dew point` 这种中文顿号。
- **深色模式（F8）**：三态（浅色 / 深色 / 跟随系统），偏好与其它显示状态同一个键。
  三件容易被忽略的事：① **刷新不能闪** —— 引导脚本必须放在 `<head>`、在 `<style>` 之前
  执行（它是产物的第 4 个内联脚本块，`syntax.py` / `assemble.py` / `globals.js` 三处都记着这个数）；
  ② **`color-scheme` 要跟着切**，否则原生 `select`／滚动条／日期选择器仍是白底；
  ③ **写进 DOM 的语义色要重画**（等级徽标、可信度档色）—— CSS 令牌换不了它们。
  **取舍**：分享卡（canvas 导出）**固定浅色**（图片要发到聊天工具里，浅底更稳妥）；
  主题**不进 URL**（设备偏好，别人发的链接不该强制你的界面变黑）；地图底图与色阶与主题无关
  （那是数据，且底图另有"深色底图"开关）。
  实现上是"只改令牌"：`<head>` 里那份 `html[data-theme="dark"]` 重新定义 `:root` 的几十个变量，
  组件 CSS 一行不改 —— 所以**浅色模式逐字未动**。
- **F3 最佳窗口（日历）**："零取数"的边界要说清楚 —— 零取数指**渲染这张日历**（只读
  `State.trend.rows`，所以切语言、切主题、随便重画都不花钱）；**点格子**是用户的显式意图
  （"我要看那天"），会照常走一次单点取数，与趋势表格里的格子行为一致。
  （踩过：`runForecast(scroll)` 的参数是"是否滚动到结果卡"，不是 cacheOnly —— 一度把它当缓存路径写进注释。）
- **F2 多观测点对比**：额度纪律的三条落法 —— ① 取数**只能**由「对比这些点」按钮触发；
  ② 命中单点缓存的点**不进请求**（用的就是普通单点缓存的键族，所以"先单独查过某点"再对比，
  那一点是零成本的）；③ 默认**只比当前时段**，坐标数是 17N 而不是 34N。
  上限 5 个点，界面上写明"本次将消耗约 N 个计费调用"。
  `spots` 存独立的 `sunsetbot.spots.v1`（这是**数据**不是显示偏好），坏值一律丢弃，
  名字走 `safeLabel`。结果在**位置 / 日期 / 时段**任一变化时作废（否则会显示上一个地点或上一天的数字）。
- **偏好持久化（B1）**：9 个**显示状态**（数值直标 / 采样点 / 可信度 / 经纬网 /
  深色底图 / 12 小时制 / 单位制 / 地图着色依据 / 算法模型）写进**同一个** `localStorage`
  键（`sunsetbot.pref.v1`，实测 112 字节），重开页自动恢复。
  **刻意不存**两类：① 位置与日期 —— 已由 URL 承载，存了会与分享链接打架；
  ② 地图时段 —— 它由单点时段派生，存了会让"地图看晚霞、上方算朝霞"成为常态。
  应用**顺序**是硬约束：必须在任何"控件初值 / 派生状态"赋值**之前**调用，否则出现
  "控件写着 A、State 是 B"的静默错位；依赖地图 DOM 的两项（经纬网、深色底图）延到
  `initMap` 末尾，且**必须早于**缓存自动加载（否则会先闪一下默认态）。
- **趋势结果缓存（B2）**：趋势窗口一次约 129 次加权调用（占单页全量 55%），所以把
  **算好的 rows** 落盘（实测 ≈1.9 KB/条，上限 3 条），重开页命中时**零请求**直接画出；
  有缓存就自动画、没缓存仍然不打扰用户（与地图 B14 同一条纪律）。
  **不存原始响应**：原始响应约 5 MB，会撑爆 5 MB 配额，导致**所有**缓存静默失效。
  代价是"权重 / 阈值一改旧缓存就错"——用 `TREND_CACHE_PREFIX` 版本号兜住。
- **F4 本地校准**：四条边界都是硬约束，改动前先看清楚。
  ① **只展示、不回改**：校准行画在结论卡**下方**一个独立块里，与 `#hero` 的
  概率/等级/环、`#models`、`#fac` 各写各的 DOM，**永不互相写**；`calibprobe` 用
  "标注前后模型指纹逐字段相同"把这条断死（概率文本 + 大数 + 徽章 + 环 `stroke-dashoffset`
  + 每个模型数字 + 因素表行数，共 136 字符）。
  ② **只在够样本时给结论**：`CALIB_MIN_N = 8`（总样本）**且** `CALIB_MIN_BUCKET = 3`
  （当前这一档）才出数字，之前只显示进度；`CALIB_BUCKET = 20`（按预测 P 每 20 个百分点一档）、
  `CALIB_GRID_DEG = 0.5`（同地区判定：`round(lat/0.5)`,`round(lon/0.5)` 同格才算）、
  `CALIB_HIT_MIN = 2`（"实际出现" = 标注 ≥「一般，能看」）。
  ③ **"没看到"不是"没有霞"**：`a = -1`（无法判断）**不计入统计**（既不进分母也不进分子），
  否则"没出门看"会被记成"预报失败"，把校准系统性拉低。
  ④ **关掉 ≠ 删除**：`#calibOff` 只关入口与展示，**已存标注一条都不删**；
  清空是另一个按钮，且要二次确认。两者都在 `sunsetbot.calib.v1` 里
  （`calibOff` 属于偏好键 `sunsetbot.pref.v1` 的白名单项，标注本身走独立键）。
  入口是否出现只认 `leadH`（**未来时段不给标注**——"还没发生"没法回填），
  与"能不能标注"复用同一个判据，不新增阈值。

[Open-Meteo](https://open-meteo.com)，省界数据来自阿里云 DataV，
地图服务来自[腾讯位置服务](https://lbs.qq.com)，请遵守各自的服务条款。
