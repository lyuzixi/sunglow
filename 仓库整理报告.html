霞光预报 · GitHub 仓库整理报告

对 github.com/lyuzixi/sunglow 现有文件逐项目的作用梳理与"可删 / 必留"归类，目标是一份简洁、可追溯、可直接部署的仓库布局。

一句话结论：真正"非它不可"的源码与交付物只有约 30 个文件（< 4.3 MB）。根目录下 14 份设计 / 规划 / 对比文档（约 0.54 MB）是历史工作稿，应移入 docs/ 或删除；_backup/(26 MB)、_scratch/(34 MB) 已被 .gitignore 忽略、可本地删除；.workbuddy/(390 KB) 是工具内部数据，本地勿删但建议移出版本库。

· index.html / 404.html 由 assemble.py 生成，禁止手改；整理后若改动源码请重新构建（SITE_BASE=sunglow python assemble.py → python mkpreview.py → python _check/all.py）。

· .workbuddy/ 含项目记忆与技能，切勿本地删除；只做"移出版本库（--cached）"即可。
· 任何 git rm / rm -rf 前请确认工作区已提交，避免误删未备份内容。
